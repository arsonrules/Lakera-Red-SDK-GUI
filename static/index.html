Any reply carrying a StreamToken opens an SSE stream on its own: the retrieved token goes where {StreamToken} is written in this URL, e.g. /path/to/{StreamToken} — left out, it is appended at the end. Each event's content is joined into the reply Red judges. An http target streams from a StreamUrl in its reply or from the target URL, so this is optional. A ws/wss target's reply names only the token, so set the https SSE endpoint here. Response path then points inside each event.
